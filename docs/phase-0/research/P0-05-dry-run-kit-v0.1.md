## 2. Printing and accessibility conventions

Use these conventions when a named human later reviews or adapts the forms:

- Print or render one numbered form at a time. Repeat column headers on every continued page.
- Never communicate state by color, position, handwriting style, or an unchecked blank alone. Write `YES`, `NO`, `N/A — reason`, or `OPEN`.
- Every detachable record block labeled `FORM` has a spoken label, stable form ID, page number, and continuation marker. Read the label before the value when used aloud. Embedded reference and case tables inherit the surrounding document's pagination and are not standalone continuation forms.
- Use ISO dates and 24-hour Pacific Time only after the operational process is approved. Synthetic rehearsal may use ordered step numbers instead of clock time.
- Use `SYN-` as the prefix for every invented rehearsal ID. Never enter a real name, handle, contact route, boundary, concern, report narrative, deletion token, or participant statement.
- Use `NONE` for a known empty field and `UNKNOWN — STOP` for a required value that cannot be established. Do not use ditto marks.
- Record dice in the order rolled. Record full zone names and condition names; do not rely on tokens or a map alone.
- A screen-reader rendering must preserve heading order, row order, field labels, checkboxes, and event sequence. Equivalent keyboard entry and spoken confirmation remain an open human-accessibility review.
- These Markdown forms are design inputs, not proof that a printed or digital implementation is accessible.
